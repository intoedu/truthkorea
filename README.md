# truthkorea

**국민주권운동 홈페이지**(국민주권운동.com)를 새로 만든 정적 웹사이트입니다.
어르신들이 쉽게 쓰실 수 있도록 **큰 글자, 늘 보이는 글자 메뉴, 크게 누르는 단추, 단순한 화면**으로 만들었습니다.

- 프로그램 설치나 빌드 과정이 없습니다. HTML·CSS·자바스크립트 파일만 있으면 어디서든 열립니다.
- 바깥 서버(CDN, 글꼴 서비스, 통계 도구 등)에 아무것도 요청하지 않습니다. 글꼴(Pretendard)도 저장소 안에 들어 있습니다.
- 신청서나 입력 칸(form)은 없습니다. 연락은 전화, 이메일, 방문 안내로만 합니다.
- **단체에 관한 실제 내용(인사말, 연혁, 주소, 전화번호 등)은 하나도 지어 넣지 않았습니다.** 모르는 내용은 모두 노란 `[입력 필요: …]` 칸으로 비워 두었습니다. 채워야 할 목록은 [CONTENT-TODO.md](CONTENT-TODO.md)에 있습니다.

## 어르신을 위한 화면 특징

- 본문 글자는 휴대전화 19px, 컴퓨터 20px 이상이며 줄 간격이 넉넉합니다. 글자와 바탕의 명암 대비는 가장 높은 기준(WCAG AAA, 7:1 이상)을 지켰습니다.
- 화면 맨 위의 **글자 크기 단추**(보통 · 크게 · 아주 크게)로 모든 글자를 키울 수 있고, 고른 크기는 다른 쪽으로 옮겨 가거나 ‘뒤로’ 단추로 돌아와도 유지됩니다. 단추를 눌러도 단추 자리는 움직이지 않습니다.
- 글자를 아주 크게 키워도 메뉴 이름이 낱말 중간에서 잘리지 않습니다. 한 줄에 다 들어가지 않으면 메뉴 칸 수가 줄어듭니다.
- 메뉴는 숨기지 않고 늘 글자로 보입니다(햄버거 단추 없음). 지금 보고 있는 쪽은 진한 색과 아래 금색 줄로 표시됩니다.
- 누르는 곳은 모두 가로·세로 48px 이상(대부분 56px)이고, 링크에는 밑줄이 있습니다.
- 휴대전화에서는 화면 아래에 **전화 걸기 · 오시는 길 · 맨 위로** 막대가 늘 있습니다. 컴퓨터에서는 머리글 오른쪽에 큰 ‘전화 문의’ 단추가 있습니다.
- 움직이는 그림, 자동으로 넘어가는 슬라이드가 없습니다. 자바스크립트가 꺼져 있어도 글자 크기 단추와 복사 단추만 빼고 모두 동작합니다.
- 키보드만으로도 쓸 수 있고(‘본문 바로가기’, 굵은 초점 표시), 인쇄하면 메뉴는 빠지고 내용만 깔끔하게 나옵니다.
- 카카오톡으로 링크를 보내면 제목과 설명이 나오도록 Open Graph 정보가 들어 있습니다.

```
README.md             이 안내서

  css/site.css        하나뿐인 스타일시트 (인쇄용 스타일 포함)
```

## 내 컴퓨터에서 미리 보기

저장소 폴더에서 아래 명령 가운데 하나를 실행한 뒤, 인터넷 브라우저에서 `http://localhost:8000/` 을 엽니다.

```
python3 -m http.server 8000
```

또는 (Node.js가 있을 때)

```
npx serve -l 8000 .
```

`index.html` 파일을 두 번 눌러 바로 열어도 대부분 보이지만, 글자 크기 기억 같은 기능을 제대로 확인하려면 위처럼 작은 서버로 여는 것이 좋습니다.
모든 주소가 상대 주소이므로 사이트를 어느 하위 폴더에 올려도 동작합니다.

```html
<span class="ph" data-ph="KEY">[입력 필요: 짧은 설명]</span>          (글 중간)
```

### 2. 채우는 방법

1. 편집기(메모장도 됩니다)의 ‘모든 파일에서 찾기’로 `data-ph="KEY"` 를 찾습니다.
2. `<span class="ph" data-ph="KEY">[입력 필요: …]</span>` 덩어리 전체를 실제 글로 바꿉니다. 긴 글(`ph-block`)은 문단마다 `<p>…</p>`로 감쌉니다.
3. 전화번호와 이메일 링크는 `href`도 함께 채우고, 링크에 붙은 `data-ph`를 지웁니다.
   - 전화: `href`에는 **하이픈 없이 숫자만**, 화면 글자에는 **하이픈을 넣어** 씁니다.
     ```html
     바꾸기 전: <a class="footer-link" href="tel:" data-ph="contact-phone"><span class="ph" data-ph="contact-phone">[입력 필요: 대표 전화번호]</span></a>
     바꾼 뒤:   <a class="footer-link" href="tel:(숫자만)">(하이픈을 넣은 번호)</a>
     ```
   - 이메일: `href="mailto:주소"`와 화면 글자 두 곳에 같은 주소를 씁니다.
4. 값을 채운 뒤에는 `data-ph`를 지웁니다.
5. 날짜는 `YYYY년 M월 D일` 형식으로 쓰고, 실제 날짜를 채울 때만 `<time datetime="YYYY-MM-DD">…</time>`로 감쌉니다.
6. 처음 화면의 ‘최근 소식’ 3개는 활동 소식 쪽 맨 위 3개 글과 제목·날짜를 같게 맞춥니다(손으로 맞춰야 합니다).

### 3. 공개 전 점검 (두 명령 모두 아무것도 출력하지 않아야 합니다)

```
grep -rn 'class="[^"]*\bph\b' *.html
grep -rnE 'href="(tel|mailto):"' *.html
```

첫 명령은 주석 속 선택 틀도 찾아냅니다. 쓰지 않을 선택 틀은 주석째 지우세요.

### 4. 노란 표시 끄기

`assets/css/site.css`에서 아래 두 주석 사이의 `.ph { … }` 규칙 **한 줄**을 지우면 노란 바탕과 점선이 모두 사라집니다.

```
/* ===== PLACEHOLDER - 이 규칙 하나를 지우면 노란 표시가 모두 사라집니다 ===== */
.ph { … }
/* ===== /PLACEHOLDER ===== */
```

- 이것은 **표시만** 없앱니다. `[입력 필요: …]` 글자는 그대로 남으니, 실제 내용을 채우는 것이 먼저입니다.
- `404.html` 머리 부분의 비상용 `<style>` 안에도 `.ph` 한 줄이 있습니다. 표시를 아주 없앨 때는 그 줄도 함께 지웁니다.
- 인쇄할 때도 채우지 않은 자리는 점선으로 표시되어, 초안 검토에 쓸 수 있습니다.

### 5. 선택 항목 켜기

HTML 주석(`<!--` 와 `-->` 사이) 속에 바로 쓸 수 있는 틀이 들어 있습니다. 주석 표시를 지우고 내용을 채우면 됩니다.

| 항목 | 위치 |
|---|---|
| 대표자, 고유번호 | 모든 쪽 바닥글의 주소 목록 아래 (6개 파일 모두 같은 틀) |
| 팩스 번호 | contact.html ‘그 밖의 연락 방법’ |
| 후원 안내(은행, 계좌번호, 예금주, 계좌번호 복사 단추) | contact.html 맨 아래 |
| 카카오맵·네이버 지도 단추 | contact.html ‘주소’ 아래 (새 창으로 열지 않습니다) |
| 약도 그림 | contact.html ‘약도’ (약도가 없으면 그 구역 전체를 지웁니다) |
| 대표 사진, 대표자 사진, 조직도, 소식 사진 | index.html, about.html, news.html |
| 자료 ‘내려받기’ 단추, 자료가 없을 때 문구 | resources.html ‘자료 목록’ 위 주석 |

### 6. 자료실 파일 올리기

- 파일은 `assets/files/` 폴더에 **영문·숫자 이름**으로 넣습니다(예: `assets/files/2026-guide.pdf`). 한글 파일 이름은 일부 휴대전화와 카카오톡 안에서 깨질 수 있습니다.
- PDF는 화면에서 바로 열리므로 `download` 속성을 붙이지 않습니다. HWP, ZIP처럼 브라우저가 열 수 없는 파일에만 붙이고, HWP는 PDF 사본도 함께 올리기를 권합니다.

### 7. 메뉴 바꾸기

옛 사이트와 메뉴 구성(처음으로 · 단체 소개 · 활동 소식 · 자료실 · 오시는 길)을 맞출 때는 아래 **모든 곳**을 함께 고칩니다.

| 어디 | 무엇 |
|---|---|
| 6개 파일 모두 | 위 메뉴(`.gnb__list`), 바닥글 메뉴(`.footer-menu__list`), ‘현재 위치’ 줄의 ‘처음으로’(404.html 제외) |
| 6개 파일 모두 | 휴대전화 아래 막대의 ‘오시는 길’(`.quickbar__item`, `contact.html#directions`로 연결) |
| index.html, 404.html | ‘자주 찾는 메뉴’ 네모 칸(`ul.tiles`) 4개 |
| index.html | ‘단체 소개 보기’, ‘소식 전체 보기’, ‘오시는 길 자세히 보기’ 단추와 ‘최근 소식’ 링크 3개(`news.html#news-N`) |
| 404.html | ‘처음 화면으로 가기’ 단추 |

쪽 파일 이름을 바꾸었다면, 마지막에 옛 이름이 남아 있지 않은지 확인합니다(아무것도 나오지 않아야 합니다).

```
grep -n 'href="옛이름.html' *.html
```

메뉴 칸은 글자 길이에 맞춰 저절로 줄을 바꿉니다. 휴대전화에서는 앞의 두 칸이 첫 줄에 오므로, 메뉴가 4개면 그대로 2 + 2가 됩니다.
6개로 늘리면 `site.css` ‘5. 주 메뉴’의 `nth-child(-n+2)`를 `nth-child(-n+3)`으로, `46%`를 `30%`로 바꾸면 3 + 3이 됩니다.

## 배포하기 (인터넷에 올리기)

이 사이트는 **정적 사이트**라서 HTML 파일을 그대로 올려 주는 곳이면 어디든 쓸 수 있습니다(웹 호스팅, 정적 사이트 호스팅 서비스, 단체가 가진 웹 서버 등). 특별한 서버 프로그램이나 데이터베이스가 필요 없습니다.

1. **옛 사이트 내용부터 보관합니다.** 도메인을 새 사이트로 옮기면 옛 화면은 더 이상 보이지 않습니다. 옮기기 전에 옛 사이트의 인사말, 연혁, 연락처, 소식, 자료 파일을 모두 복사해 두고, 그 내용으로 노란 칸을 채웁니다.
2. 저장소의 파일을 **폴더 구조 그대로** 호스팅 공간의 맨 위(웹 문서 폴더)에 올립니다. `.git` 폴더와 `README.md`, `CONTENT-TODO.md`는 올리지 않아도 됩니다.
3. 호스팅 설정에서 기본 문서는 `index.html`, 오류(찾을 수 없음) 쪽은 `404.html`로 지정합니다. **도메인 맨 위(`국민주권운동.com/`)에 올릴 때는 아래 8번을 꼭 합니다.**
4. 호스팅에서 받은 임시 주소로 열어 보고, 모든 쪽과 휴대전화 화면을 확인합니다.
5. **도메인 연결(DNS)**: 도메인을 산 곳(도메인 등록 업체)의 DNS 관리 화면에서, 호스팅 업체가 안내하는 값으로 기록을 고칩니다. 일반적으로는
   - 맨 앞에 아무것도 없는 주소(`국민주권운동.com`, 표시 이름 `@`)는 **A 기록**(호스팅이 알려 준 IP 주소) 또는 호스팅이 지원하는 방식으로,
   - `www` 주소는 **CNAME 기록**(호스팅이 알려 준 주소)으로 연결합니다.
   - 한글 도메인은 관리 화면에 따라 영문 변환 이름(퓨니코드) **`xn--3e0b9b67w9mjb2nckd.com`** 으로 입력해야 할 수 있습니다.
   - 바뀐 기록이 퍼지는 데는 몇 분에서 길게는 하루 이상 걸릴 수 있습니다. 그동안 옛 화면과 새 화면이 번갈아 보일 수 있습니다.
6. **보안 연결(HTTPS)** 인증서를 켭니다. 대부분의 호스팅에서 자동 발급 기능을 제공합니다. 켠 뒤 `http://` 주소가 `https://`로 넘어가는지 확인합니다.
7. **카카오톡 미리보기 그림**: 주소가 확정되면 각 쪽 `<head>`의 주석 자리(`og:image / og:url`)에 **절대 주소**로 `og:image`(가로로 긴 대표 그림, 예: `https://(도메인)/assets/img/og.png`)와 `og:url`을 추가합니다. 카카오톡은 미리보기를 한동안 저장해 두므로, 고친 뒤에는 카카오 개발자 사이트의 공유 디버거에서 해당 주소의 캐시를 지워 줍니다.
8. **404 쪽 주소 바꾸기 (도메인 맨 위에 올릴 때 반드시)**: 옛 사이트의 즐겨찾기·검색 결과·카카오톡 공유 링크는 대개 `/board/view.php`처럼 하위 폴더 경로입니다. 호스팅은 그런 없는 주소에서 `404.html`을 **그 경로 그대로** 보여 주므로, 상대 주소로 된 스타일·글꼴·메뉴 링크가 모두 그 없는 폴더 안을 가리켜 깨지고, ‘처음 화면으로 가기’ 단추도 또 다른 없는 쪽으로 갑니다.
   - 그래서 **올리는 사본의 `404.html` 하나만** 주소를 `/`로 시작하게 바꿉니다(다른 쪽 파일은 그대로 둡니다). 저장소 맨 위 폴더에서:
     ```
     sed -i -E 's#(href|src)="(assets/|index\.html|about\.html|news\.html|resources\.html|contact\.html)#\1="/\2#g' 404.html
     ```
     (맥에서는 `sed -i '' -E …`. 명령을 쓸 수 없으면 편집기의 ‘바꾸기’로 `href="assets/`→`href="/assets/`, `src="assets/`→`src="/assets/`, `href="index.html`→`href="/index.html`처럼 404.html 안의 다섯 쪽 이름과 `assets/` 앞에 `/`를 붙입니다. `#main`, `#top`, `tel:`은 그대로 둡니다.)
   - 바꾼 뒤 `https://(도메인)/없는/주소` 를 열어 글꼴·메뉴가 제대로 보이고 ‘처음 화면으로 가기’가 처음 화면으로 가는지 확인합니다.
   - 사이트를 하위 폴더(예: `/home/`)에 올릴 때는 이 명령 대신 `/` 자리에 그 폴더 경로(`/home/`)를 넣거나, 호스팅의 ‘주소 넘겨주기(redirect)’ 설정으로 옛 주소를 처음 화면으로 보냅니다.
   - 만약 404.html이 스타일 없이 열리더라도 읽을 수 있도록, 404.html 머리 부분에 최소한의 비상용 스타일이 들어 있습니다.
